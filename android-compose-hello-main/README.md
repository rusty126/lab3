# Profile App — экран профиля на Jetpack Compose

## Описание проекта
Учебное Android-приложение с интерактивным экраном профиля пользователя. Интерфейс реализован на Kotlin с помощью Jetpack Compose и Material 3.

## Функциональность
- Круглый аватар с инициалами пользователя.
- Отображение ФИО, статуса и количества подписчиков.
- Переключение подписки с обновлением счётчика подписчиков.
- Редактирование ФИО через `OutlinedTextField` и возврат к исходному значению кнопкой «Сбросить».
- Счётчик нажатий с кнопкой «+».
- Переключение светлой и тёмной темы.
- Анимация масштаба и цвета кнопки подписки.
- Отдельные компоненты и Preview-функции.

## Технологии
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Минимальная версия Android: API 24

## Структура проекта
- `app/src/main/java/com/example/hello/MainActivity.kt` — точка входа и тема приложения.
- `data/User.kt` — модель пользователя.
- `ui/ProfileScreen.kt` — основной экран и состояние интерфейса.
- `ui/components/Avatar.kt` — аватар.
- `ui/components/ProfileInfo.kt` — информация профиля.
- `ui/components/ActionButtons.kt` — кнопки действий.

## Запуск
1. Откройте проект в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Запустите приложение на эмуляторе или Android-устройстве.
